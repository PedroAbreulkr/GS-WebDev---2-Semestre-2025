# WorkFuture

Projeto desenvolvido para a Global Solution da FIAP, focado em criar uma
plataforma para busca e visualização de profissionais, suas habilidades
e perfis completos.

## Objetivo

Criar um site responsivo que permite: - Buscar profissionais por nome ou
cargo - Filtrar por área, cidade e tecnologia - Visualizar perfis
completos em um modal - Navegar entre páginas (Home, About, Contact)

## Funcionalidades

-   Filtros dinâmicos
-   Cards de profissionais
-   Modal detalhado
-   Modo claro/escuro
-   Sistema de rotas (React Router)
-   Formulário de contato
-   Dados reais + dados gerados automaticamente

## Tecnologias Utilizadas

-   React
-   Vite
-   React Router DOM
-   CSS
-   JavaScript ES6

------------------------------------------------------------------------

## 📌 Resumo do Projeto

O WorkFuture é uma aplicação React projetada para facilitar a busca por
profissionais, permitindo filtragem avançada e exibição detalhada de
perfis.\
O sistema oferece uma interface moderna, responsiva e intuitiva, com
suporte a modo claro/escuro, rotas separadas e carregamento dinâmico de
informações.

## 🔧 Instalação do Projeto -- Passo a Passo

1.  **Clone o repositório**

    ``` bash
    git clone https://github.com/PedroAbreulkr/GS-WebDev---2-Semestre-2025
    ```

2.  **Acesse o diretório**

    ``` bash
    cd workfuture
    ```

3.  **Instale as dependências**

    ``` bash
    npm install
    ```

4.  **Execute o projeto**

    ``` bash
    npm run dev
    ```

5.  **Acesse no navegador**

        http://localhost:5173
